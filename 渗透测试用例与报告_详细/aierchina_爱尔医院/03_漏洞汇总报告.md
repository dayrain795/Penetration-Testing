# 03 安全测试结果汇总报告

**测试对象**：爱尔医院
**分级标准**：GB/T 30279-2020（高危/中危/低危/信息）；信息级为配置优化建议，不属于安全漏洞。

## 一、风险统计总览

| 风险等级 | 数量 | 说明 |
| :--- | :--- | :--- |
| 高危 | 0 | 未发现可直接获取系统权限、核心数据或大规模敏感信息泄露的问题 |
| 中危 | 0 | 需一定条件利用、可造成有限敏感信息泄露或防护绕过的问题 |
| 低危 | 1 | 信息泄露、配置缺陷等难以直接形成攻击链的问题 |
| 信息 | 2 | 配置优化建议/安全预警，不属于漏洞 |

## 二、安全漏洞明细

### VULN-01：异常请求回显中间件类型信息

| 项目 | 内容 |
| :--- | :--- |
| 风险等级 | 低危 |
| WSTG编号 | WSTG-CONF-002 |
| 受影响资产 | 爱尔医院相关Web资产 |
| 漏洞描述 | 对站点提交异常URL时，自定义错误页中回显了中间件类型与错误处理组件特征，可辅助攻击者识别技术栈。 |
| 复现步骤 | 1.使用Burp Suite向随机路径发送畸形请求；2.观察错误页中回显的Server组件特征与调试字段；3.多次验证确认信息稳定回显。 |
| 定级依据（GB/T 30279-2020） | 依据GB/T 30279-2020，信息泄露内容限于组件类型、无版本号与敏感路径，利用需结合其他条件，定为低危。 |
| 修复建议 | 统一自定义错误页面，关闭详细错误模式，错误响应仅返回标准化提示。 |


## 三、信息级安全配置建议（非漏洞）

**IN-01（对应TC-10）：HTTP安全响应头配置不完整**

- 现象说明：目标站点响应头中缺少Content-Security-Policy、Referrer-Policy等安全头，属于配置优化项。
- 加固建议：在中间件层补齐CSP、Referrer-Policy、Permissions-Policy等响应头并灰度验证。

**IN-02（对应TC-11）：目录浏览策略建议加固**

- 现象说明：经核验目录列表处于关闭状态，建议在配置基线中显式禁用并纳入巡检。
- 加固建议：在Nginx/Apache配置中显式关闭autoindex/Options Indexes。


## 四、总体评价

爱尔医院本次测试共覆盖28项WSTG标准测试点与若干专项扩展验证。系统核心安全机制（认证鉴权、输入验证、访问控制、会话管理、文件处理）整体有效，未发现高危漏洞；中低危问题数量少且利用条件受限。建议优先处置中危项并将信息级建议纳入日常配置基线，定期复测。
