# 03 安全测试结果汇总报告

**测试对象**：长沙医学院
**分级标准**：GB/T 30279-2020（高危/中危/低危/信息）；信息级为配置优化建议，不属于安全漏洞。

## 一、风险统计总览

| 风险等级 | 数量 | 说明 |
| :--- | :--- | :--- |
| 高危 | 0 | 未发现可直接获取系统权限、核心数据或大规模敏感信息泄露的问题 |
| 中危 | 1 | 需一定条件利用、可造成有限敏感信息泄露或防护绕过的问题 |
| 低危 | 1 | 信息泄露、配置缺陷等难以直接形成攻击链的问题 |
| 信息 | 2 | 配置优化建议/安全预警，不属于漏洞 |

## 二、安全漏洞明细

### VULN-01：密码找回校验接口缺少频控与验证码可枚举账号绑定信息

| 项目 | 内容 |
| :--- | :--- |
| 风险等级 | 中危 |
| WSTG编号 | WSTG-BUSL-005 |
| 受影响资产 | 长沙医学院相关Web资产 |
| 漏洞描述 | 密码找回流程中的校验接口未要求图形验证码且无有效频率限制，攻击者可低速率枚举学号/账号，根据响应差异判断账号是否存在及绑定状态，形成账号枚举与后续钓鱼/撞库风险。 |
| 复现步骤 | 1.进入密码找回页面抓包定位校验接口；2.不传验证码依次提交存在与不存在的账号；3.比对响应报文差异（提示文案/状态码/响应长度）；4.以2秒间隔连续验证多个账号确认无锁定与频控；5.根据差异稳定枚举出有效账号（测试中已手工验证数十个样本即停止，未做批量遍历）。 |
| 定级依据（GB/T 30279-2020） | 依据GB/T 30279-2020，接口未授权可访问、可稳定区分有效账号、且无任何频率限制，可被用于批量账号枚举并辅助后续攻击，但未直接泄露密码或个人敏感数据，定为中危。 |
| 修复建议 | 接口增加图形/滑块验证码；账号维度与IP维度双重限流（如5次/小时）；统一响应文案与长度，消除可枚举差异；异常枚举触发告警。 |

### VULN-02：部分子系统会话Cookie缺少SameSite属性

| 项目 | 内容 |
| :--- | :--- |
| 风险等级 | 低危 |
| WSTG编号 | WSTG-SESS-002 |
| 受影响资产 | 长沙医学院相关Web资产 |
| 漏洞描述 | 个别子系统会话Cookie未设置SameSite，跨站请求防护依赖服务端Token。 |
| 复现步骤 | 1.登录各子系统抓取Set-Cookie；2.逐一核对HttpOnly/Secure/SameSite；3.确认SameSite缺失且无其他CSRF补偿措施。 |
| 定级依据（GB/T 30279-2020） | 属性缺失可被CSRF类攻击利用，但需用户交互且接口另有Token校验，定为低危。 |
| 修复建议 | 为会话Cookie补充SameSite=Lax，并同步核查CSRF Token覆盖范围。 |


## 三、信息级安全配置建议（非漏洞）

**IN-01（对应TC-10）：HTTP安全响应头配置不完整**

- 现象说明：部分业务子系统安全响应头不齐全。
- 加固建议：统一接入网关层安全头基线。

**IN-02（对应TC-07）：技术栈信息暴露建议**

- 现象说明：部分接口错误响应可识别后端框架特征。
- 加固建议：统一异常处理，屏蔽框架特征。


## 四、总体评价

长沙医学院本次测试共覆盖28项WSTG标准测试点与若干专项扩展验证。系统核心安全机制（认证鉴权、输入验证、访问控制、会话管理、文件处理）整体有效，未发现高危漏洞；中低危问题数量少且利用条件受限。建议优先处置中危项并将信息级建议纳入日常配置基线，定期复测。
