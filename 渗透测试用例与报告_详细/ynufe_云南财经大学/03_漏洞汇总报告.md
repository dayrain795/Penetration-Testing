# 03 安全测试结果汇总报告

**测试对象**：云南财经大学
**分级标准**：GB/T 30279-2020（高危/中危/低危/信息）；信息级为配置优化建议，不属于安全漏洞。

## 一、风险统计总览

| 风险等级 | 数量 | 说明 |
| :--- | :--- | :--- |
| 高危 | 0 | 未发现可直接获取系统权限、核心数据或大规模敏感信息泄露的问题 |
| 中危 | 0 | 需一定条件利用、可造成有限敏感信息泄露或防护绕过的问题 |
| 低危 | 1 | 信息泄露、配置缺陷等难以直接形成攻击链的问题 |
| 信息 | 3 | 配置优化建议/安全预警，不属于漏洞 |

## 二、安全漏洞明细

### VULN-01：公开公示页面个人信息脱敏不足

| 项目 | 内容 |
| :--- | :--- |
| 风险等级 | 低危 |
| WSTG编号 | WSTG-BUSL-001 |
| 受影响资产 | 云南财经大学相关Web资产 |
| 漏洞描述 | 奖助学金等公示文件在公网可直接下载查看，文件中包含学生完整姓名、学号、专业、民族等个人信息，脱敏不充分。 |
| 复现步骤 | 1.通过站内检索定位公示文件；2.直接下载PDF/Excel；3.核验文件内个人信息字段完整度；4.确认无需登录即可访问。 |
| 定级依据（GB/T 30279-2020） | 信息来自学校主动公示但超出必要公开范围，未见身份证号等高度敏感字段，定为低危。 |
| 修复建议 | 公示文件对学号、手机号等做部分掩码，提供公开查阅与明细下载分离机制，过期文件及时下线。 |


## 三、信息级安全配置建议（非漏洞）

**IN-01（对应TC-10）：HTTP安全响应头配置不完整**

- 现象说明：部分系统安全头不齐全。
- 加固建议：补齐安全头。

**IN-02（对应TC-08）：备份文件探测预警**

- 现象说明：对备份类路径的探测均返回403/404，建议维持当前策略。
- 加固建议：保持目录访问控制并定期巡检。

**IN-03（对应TC-09）：服务器版本信息收敛建议**

- 现象说明：响应头可识别服务器类型。
- 加固建议：隐藏版本。


## 四、总体评价

云南财经大学本次测试共覆盖28项WSTG标准测试点与若干专项扩展验证。系统核心安全机制（认证鉴权、输入验证、访问控制、会话管理、文件处理）整体有效，未发现高危漏洞；中低危问题数量少且利用条件受限。建议优先处置中危项并将信息级建议纳入日常配置基线，定期复测。
