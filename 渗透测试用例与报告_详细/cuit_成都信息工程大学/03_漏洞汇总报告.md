# 03 安全测试结果汇总报告

**测试对象**：成都信息工程大学
**分级标准**：GB/T 30279-2020（高危/中危/低危/信息）；信息级为配置优化建议，不属于安全漏洞。

## 一、风险统计总览

| 风险等级 | 数量 | 说明 |
| :--- | :--- | :--- |
| 高危 | 0 | 未发现可直接获取系统权限、核心数据或大规模敏感信息泄露的问题 |
| 中危 | 0 | 需一定条件利用、可造成有限敏感信息泄露或防护绕过的问题 |
| 低危 | 1 | 信息泄露、配置缺陷等难以直接形成攻击链的问题 |
| 信息 | 2 | 配置优化建议/安全预警，不属于漏洞 |

## 二、安全漏洞明细

### VULN-01：前端静态资源中包含内部网络地址

| 项目 | 内容 |
| :--- | :--- |
| 风险等级 | 低危 |
| WSTG编号 | WSTG-INFO-003 |
| 受影响资产 | 成都信息工程大学相关Web资产 |
| 漏洞描述 | 页面引用的前端配置脚本中包含内部网段地址与内部系统标识，属于信息泄露。 |
| 复现步骤 | 1.审查页面加载的JS配置文件；2.检索10.、172.16.等内网地址；3.确认该地址不出现在任何公网响应中。 |
| 定级依据（GB/T 30279-2020） | 泄露内容为内网网段描述，无法直接从公网访问，定为低危。 |
| 修复建议 | 发布构建时剔除内网配置，前端仅保留公网可达地址。 |


## 三、信息级安全配置建议（非漏洞）

**IN-01（对应TC-10）：HTTP安全响应头配置不完整**

- 现象说明：部分业务系统缺少CSP响应头。
- 加固建议：在反向代理层统一补齐。

**IN-02（对应TC-12）：默认路径访问收敛建议**

- 现象说明：个别默认路径可访问到登录页，建议来源限制。
- 加固建议：默认示例页移除，管理路径限制来源。


## 四、总体评价

成都信息工程大学本次测试共覆盖28项WSTG标准测试点与若干专项扩展验证。系统核心安全机制（认证鉴权、输入验证、访问控制、会话管理、文件处理）整体有效，未发现高危漏洞；中低危问题数量少且利用条件受限。建议优先处置中危项并将信息级建议纳入日常配置基线，定期复测。
