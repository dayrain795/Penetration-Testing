# 03 安全测试结果汇总报告

**测试对象**：汕头大学医学院第一附属医院
**分级标准**：GB/T 30279-2020（高危/中危/低危/信息）；信息级为配置优化建议，不属于安全漏洞。

## 一、风险统计总览

| 风险等级 | 数量 | 说明 |
| :--- | :--- | :--- |
| 高危 | 0 | 未发现可直接获取系统权限、核心数据或大规模敏感信息泄露的问题 |
| 中危 | 0 | 需一定条件利用、可造成有限敏感信息泄露或防护绕过的问题 |
| 低危 | 0 | 信息泄露、配置缺陷等难以直接形成攻击链的问题 |
| 信息 | 1 | 配置优化建议/安全预警，不属于漏洞 |

**结论：本次测试范围内未发现安全漏洞，仅存在信息级配置优化建议。**


## 二、安全漏洞明细

本次测试未发现高、中、低危安全漏洞。


## 三、信息级安全配置建议（非漏洞）

**IN-01（对应TC-10）：HTTP安全响应头可进一步完善**

- 现象说明：安全头基本齐全，建议补充CSP。
- 加固建议：增加CSP策略。


## 四、总体评价

汕头大学医学院第一附属医院本次测试共覆盖28项WSTG标准测试点与若干专项扩展验证。系统核心安全机制（认证鉴权、输入验证、访问控制、会话管理、文件处理）整体有效，未发现高危漏洞；中低危问题数量少且利用条件受限。建议优先处置中危项并将信息级建议纳入日常配置基线，定期复测。
