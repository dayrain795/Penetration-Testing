# 03 安全测试结果汇总报告

**测试对象**：东北电力大学
**分级标准**：GB/T 30279-2020（高危/中危/低危/信息）；信息级为配置优化建议，不属于安全漏洞。

## 一、风险统计总览

| 风险等级 | 数量 | 说明 |
| :--- | :--- | :--- |
| 高危 | 0 | 未发现可直接获取系统权限、核心数据或大规模敏感信息泄露的问题 |
| 中危 | 0 | 需一定条件利用、可造成有限敏感信息泄露或防护绕过的问题 |
| 低危 | 1 | 信息泄露、配置缺陷等难以直接形成攻击链的问题 |
| 信息 | 1 | 配置优化建议/安全预警，不属于漏洞 |

## 二、安全漏洞明细

### VULN-01：版本控制元数据目录可被探测

| 项目 | 内容 |
| :--- | :--- |
| 风险等级 | 低危 |
| WSTG编号 | WSTG-INFO-003 |
| 受影响资产 | 东北电力大学相关Web资产 |
| 漏洞描述 | 邮件服务站点下存在可被探测的版本控制元数据目录特征，存在源码信息泄露隐患。 |
| 复现步骤 | 1.对站点做目录扫描；2.发现版本控制元数据路径；3.手工访问确认返回元数据特征而非404。 |
| 定级依据（GB/T 30279-2020） | 当前未获取到完整源码与凭据，但目录可探测已构成信息泄露，定为低危。 |
| 修复建议 | 删除Web目录下的版本控制元数据，发布流程与代码库物理隔离。 |


## 三、信息级安全配置建议（非漏洞）

**IN-01（对应TC-10）：HTTP安全响应头可进一步完善**

- 现象说明：邮件系统等安全头可补充CSP。
- 加固建议：补齐安全响应头。


## 四、总体评价

东北电力大学本次测试共覆盖28项WSTG标准测试点与若干专项扩展验证。系统核心安全机制（认证鉴权、输入验证、访问控制、会话管理、文件处理）整体有效，未发现高危漏洞；中低危问题数量少且利用条件受限。建议优先处置中危项并将信息级建议纳入日常配置基线，定期复测。
