# 03 安全测试结果汇总报告

**测试对象**：武汉农业科学院
**分级标准**：GB/T 30279-2020（高危/中危/低危/信息）；信息级为配置优化建议，不属于安全漏洞。

## 一、风险统计总览

| 风险等级 | 数量 | 说明 |
| :--- | :--- | :--- |
| 高危 | 0 | 未发现可直接获取系统权限、核心数据或大规模敏感信息泄露的问题 |
| 中危 | 0 | 需一定条件利用、可造成有限敏感信息泄露或防护绕过的问题 |
| 低危 | 1 | 信息泄露、配置缺陷等难以直接形成攻击链的问题 |
| 信息 | 2 | 配置优化建议/安全预警，不属于漏洞 |

## 二、安全漏洞明细

### VULN-01：公开页面可聚合大量人员邮箱

| 项目 | 内容 |
| :--- | :--- |
| 风险等级 | 低危 |
| WSTG编号 | WSTG-INFO-005 |
| 受影响资产 | 武汉农业科学院相关Web资产 |
| 漏洞描述 | 多个公开页面中的联系邮箱可被批量聚合，存在被用于钓鱼与垃圾邮件的风险。 |
| 复现步骤 | 1.遍历公开栏目收集页面；2.正则聚合页面中的邮箱地址；3.确认可获取数十个内部邮箱；4.未做登录绕过，仅采集主动公开内容。 |
| 定级依据（GB/T 30279-2020） | 邮箱为单位主动公开信息，无凭据或个人隐私字段，定为低危。 |
| 修复建议 | 页面邮箱使用图片或混淆形式展示，重要邮箱启用反垃圾策略与SPF/DKIM/DMARC。 |


## 三、信息级安全配置建议（非漏洞）

**IN-01（对应TC-10）：HTTP安全响应头配置不完整**

- 现象说明：主站安全头不齐全。
- 加固建议：补齐安全头。

**IN-02（对应TC-09）：服务器版本信息收敛建议**

- 现象说明：响应头可识别服务器类型。
- 加固建议：隐藏版本。


## 四、总体评价

武汉农业科学院本次测试共覆盖28项WSTG标准测试点与若干专项扩展验证。系统核心安全机制（认证鉴权、输入验证、访问控制、会话管理、文件处理）整体有效，未发现高危漏洞；中低危问题数量少且利用条件受限。建议优先处置中危项并将信息级建议纳入日常配置基线，定期复测。
