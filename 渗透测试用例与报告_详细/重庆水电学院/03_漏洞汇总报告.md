# 03 安全测试结果汇总报告

**测试对象**：重庆水电学院
**分级标准**：GB/T 30279-2020（高危/中危/低危/信息）；信息级为配置优化建议，不属于安全漏洞。

## 一、风险统计总览

| 风险等级 | 数量 | 说明 |
| :--- | :--- | :--- |
| 高危 | 0 | 未发现可直接获取系统权限、核心数据或大规模敏感信息泄露的问题 |
| 中危 | 0 | 需一定条件利用、可造成有限敏感信息泄露或防护绕过的问题 |
| 低危 | 1 | 信息泄露、配置缺陷等难以直接形成攻击链的问题 |
| 信息 | 1 | 配置优化建议/安全预警，不属于漏洞 |

## 二、安全漏洞明细

### VULN-01：应用监控端点路径可访问

| 项目 | 内容 |
| :--- | :--- |
| 风险等级 | 低危 |
| WSTG编号 | WSTG-CONF-008 |
| 受影响资产 | 重庆水电学院相关Web资产 |
| 漏洞描述 | 某业务系统的Spring Boot Actuator风格监控端点路径可访问到基础健康信息页。 |
| 复现步骤 | 1.目录扫描发现监控端点路径；2.未登录直接访问；3.确认仅返回基础健康状态，环境变量与敏感端点已返回403。 |
| 定级依据（GB/T 30279-2020） | 敏感端点已受限，仅健康信息可达，定为低危。 |
| 修复建议 | 监控端点统一加认证或限制来源，关闭不必要的暴露端点。 |


## 三、信息级安全配置建议（非漏洞）

**IN-01（对应TC-10）：HTTP安全响应头配置不完整**

- 现象说明：部分系统安全头不齐全。
- 加固建议：统一补齐安全头。


## 四、总体评价

重庆水电学院本次测试共覆盖28项WSTG标准测试点与若干专项扩展验证。系统核心安全机制（认证鉴权、输入验证、访问控制、会话管理、文件处理）整体有效，未发现高危漏洞；中低危问题数量少且利用条件受限。建议优先处置中危项并将信息级建议纳入日常配置基线，定期复测。
