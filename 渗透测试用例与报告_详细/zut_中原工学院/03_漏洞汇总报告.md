# 03 安全测试结果汇总报告

**测试对象**：中原工学院
**分级标准**：GB/T 30279-2020（高危/中危/低危/信息）；信息级为配置优化建议，不属于安全漏洞。

## 一、风险统计总览

| 风险等级 | 数量 | 说明 |
| :--- | :--- | :--- |
| 高危 | 0 | 未发现可直接获取系统权限、核心数据或大规模敏感信息泄露的问题 |
| 中危 | 0 | 需一定条件利用、可造成有限敏感信息泄露或防护绕过的问题 |
| 低危 | 1 | 信息泄露、配置缺陷等难以直接形成攻击链的问题 |
| 信息 | 2 | 配置优化建议/安全预警，不属于漏洞 |

## 二、安全漏洞明细

### VULN-01：系统状态接口未授权返回部署信息

| 项目 | 内容 |
| :--- | :--- |
| 风险等级 | 低危 |
| WSTG编号 | WSTG-ATHZ-003 |
| 受影响资产 | 中原工学院相关Web资产 |
| 漏洞描述 | 统一认证平台的状态查询接口可未授权访问，返回部署状态、组件标识等运行信息。 |
| 复现步骤 | 1.抓包发现状态接口；2.清空会话后直接请求；3.确认返回部署状态与组件标识；4.重复验证无需认证。 |
| 定级依据（GB/T 30279-2020） | 返回内容为运行状态而非业务数据，定为低危。 |
| 修复建议 | 状态接口增加来源限制或认证，最小化返回字段。 |


## 三、信息级安全配置建议（非漏洞）

**IN-01（对应TC-10）：HTTP安全响应头配置不完整**

- 现象说明：认证与教务系统安全头不齐全。
- 加固建议：补齐安全头。

**IN-02（对应TC-09）：服务器版本信息收敛建议**

- 现象说明：响应头可识别容器类型。
- 加固建议：隐藏版本。


## 四、总体评价

中原工学院本次测试共覆盖28项WSTG标准测试点与若干专项扩展验证。系统核心安全机制（认证鉴权、输入验证、访问控制、会话管理、文件处理）整体有效，未发现高危漏洞；中低危问题数量少且利用条件受限。建议优先处置中危项并将信息级建议纳入日常配置基线，定期复测。
