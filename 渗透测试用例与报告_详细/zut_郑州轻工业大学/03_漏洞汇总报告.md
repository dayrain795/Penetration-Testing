# 03 安全测试结果汇总报告

**测试对象**：郑州轻工业大学
**分级标准**：GB/T 30279-2020（高危/中危/低危/信息）；信息级为配置优化建议，不属于安全漏洞。

## 一、风险统计总览

| 风险等级 | 数量 | 说明 |
| :--- | :--- | :--- |
| 高危 | 0 | 未发现可直接获取系统权限、核心数据或大规模敏感信息泄露的问题 |
| 中危 | 0 | 需一定条件利用、可造成有限敏感信息泄露或防护绕过的问题 |
| 低危 | 1 | 信息泄露、配置缺陷等难以直接形成攻击链的问题 |
| 信息 | 2 | 配置优化建议/安全预警，不属于漏洞 |

## 二、安全漏洞明细

### VULN-01：统一认证登出接口存在开放重定向

| 项目 | 内容 |
| :--- | :--- |
| 风险等级 | 低危 |
| WSTG编号 | WSTG-BUSL-006 |
| 受影响资产 | 郑州轻工业大学相关Web资产 |
| 漏洞描述 | 认证平台登出接口的service参数未校验跳转目标，登录后/登出后可被引导至任意外部站点。 |
| 复现步骤 | 1.抓包定位登出接口与service参数；3.将service替换为外部域名；2.提交请求观察302跳转；4.确认可跳转至未授权外部站点。 |
| 定级依据（GB/T 30279-2020） | 开放重定向需用户点击，不能直接窃取凭据，定为低危。 |
| 修复建议 | 对service参数做白名单校验，仅允许校内域名跳转。 |


## 三、信息级安全配置建议（非漏洞）

**IN-01（对应TC-10）：HTTP安全响应头配置不完整**

- 现象说明：部分系统缺少CSP。
- 加固建议：补齐安全头。

**IN-02（对应TC-09）：组件版本信息暴露建议**

- 现象说明：部分组件版本页可识别版本号。
- 加固建议：升级组件并隐藏版本页。


## 四、总体评价

郑州轻工业大学本次测试共覆盖28项WSTG标准测试点与若干专项扩展验证。系统核心安全机制（认证鉴权、输入验证、访问控制、会话管理、文件处理）整体有效，未发现高危漏洞；中低危问题数量少且利用条件受限。建议优先处置中危项并将信息级建议纳入日常配置基线，定期复测。
