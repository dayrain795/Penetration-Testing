# 03 安全测试结果汇总报告

**测试对象**：四川财经职业学院
**分级标准**：GB/T 30279-2020（高危/中危/低危/信息）；信息级为配置优化建议，不属于安全漏洞。

## 一、风险统计总览

| 风险等级 | 数量 | 说明 |
| :--- | :--- | :--- |
| 高危 | 0 | 未发现可直接获取系统权限、核心数据或大规模敏感信息泄露的问题 |
| 中危 | 1 | 需一定条件利用、可造成有限敏感信息泄露或防护绕过的问题 |
| 低危 | 0 | 信息泄露、配置缺陷等难以直接形成攻击链的问题 |
| 信息 | 2 | 配置优化建议/安全预警，不属于漏洞 |

## 二、安全漏洞明细

### VULN-01：OA系统SOAP服务WSDL及查询方法可未授权访问

| 项目 | 内容 |
| :--- | :--- |
| 风险等级 | 中危 |
| WSTG编号 | WSTG-ATHZ-003 |
| 受影响资产 | 四川财经职业学院相关Web资产 |
| 漏洞描述 | OA协同办公系统的WorkflowService SOAP服务WSDL文档可未授权获取，且部分查询类方法在无会话状态下返回流程类型、人员标识等内部元数据，攻击者可据此梳理组织架构与业务流程，为进一步攻击提供信息基础。 |
| 复现步骤 | 1.访问/services/WorkflowService?wsdl获取完整WSDL文档；2.解析其中暴露的全部方法定义；3.使用Burp Suite构造SOAP请求调用查询类方法（不带Cookie）；4.确认响应中返回流程分类、人员ID等元数据；5.对写入类方法测试确认被拒绝（RELOGIN）。 |
| 定级依据（GB/T 30279-2020） | 依据GB/T 30279-2020，未授权可获取内部业务结构与人员元数据，泄露面超过一般信息项，但未获取具体业务单据内容与凭据，定为中危。 |
| 修复建议 | 对SOAP端点增加认证校验，WSDL不对外发布；在网关层限制/services路径来源；最小化暴露的方法清单。 |


## 三、信息级安全配置建议（非漏洞）

**IN-01（对应TC-10）：HTTP安全响应头配置不完整**

- 现象说明：OA系统安全头不齐全。
- 加固建议：补齐安全头。

**IN-02（对应TC-08）：敏感文件探测预警**

- 现象说明：目录扫描发现部分配置类路径，访问均返回登录页，建议保持收敛。
- 加固建议：保持403/登录页策略并定期巡检。


## 四、总体评价

四川财经职业学院本次测试共覆盖28项WSTG标准测试点与若干专项扩展验证。系统核心安全机制（认证鉴权、输入验证、访问控制、会话管理、文件处理）整体有效，未发现高危漏洞；中低危问题数量少且利用条件受限。建议优先处置中危项并将信息级建议纳入日常配置基线，定期复测。
