# 03 安全测试结果汇总报告

**测试对象**：沈阳工学院
**分级标准**：GB/T 30279-2020（高危/中危/低危/信息）；信息级为配置优化建议，不属于安全漏洞。

## 一、风险统计总览

| 风险等级 | 数量 | 说明 |
| :--- | :--- | :--- |
| 高危 | 0 | 未发现可直接获取系统权限、核心数据或大规模敏感信息泄露的问题 |
| 中危 | 1 | 需一定条件利用、可造成有限敏感信息泄露或防护绕过的问题 |
| 低危 | 1 | 信息泄露、配置缺陷等难以直接形成攻击链的问题 |
| 信息 | 2 | 配置优化建议/安全预警，不属于漏洞 |

## 二、安全漏洞明细

### VULN-01：统一认证会话Cookie关键安全属性组合缺失

| 项目 | 内容 |
| :--- | :--- |
| 风险等级 | 中危 |
| WSTG编号 | WSTG-SESS-002 |
| 受影响资产 | 沈阳工学院相关Web资产 |
| 漏洞描述 | 统一身份认证及部分业务系统的会话Cookie同时缺失HttpOnly与Secure属性，结合页面存在的JSONP类接口，会话令牌存在被脚本读取与明文通道窃取的组合风险。 |
| 复现步骤 | 1.完成统一认证登录并抓取Set-Cookie；2.核验会话Cookie的HttpOnly、Secure、SameSite三项属性；3.确认会话标识未设置HttpOnly，且HTTPS站点未设置Secure；4.在测试页面验证document.cookie可读取该标识；5.评估与现有接口组合后的会话泄露路径（仅做读取验证，未实施劫持）。 |
| 定级依据（GB/T 30279-2020） | 依据GB/T 30279-2020，核心会话标识同时缺少两项关键属性，被窃取后可直接冒用登录态，但实际利用需配合XSS或中间人位置，定为中危。 |
| 修复建议 | 为全部会话Cookie增加HttpOnly、Secure、SameSite=Lax；全站强制HTTPS并启用HSTS；对历史Cookie命名空间做清理。 |

### VULN-02：数据库监控控制台路径可未授权打开登录页

| 项目 | 内容 |
| :--- | :--- |
| 风险等级 | 低危 |
| WSTG编号 | WSTG-CONF-008 |
| 受影响资产 | 沈阳工学院相关Web资产 |
| 漏洞描述 | 数据库连接池监控控制台路径可直接访问到登录/监控页面，虽未进入数据视图，但暴露了监控入口。 |
| 复现步骤 | 1.目录扫描发现监控控制台路径；2.浏览器直接访问；3.确认无需认证即可打开控制台页面框架。 |
| 定级依据（GB/T 30279-2020） | 未获取监控数据，但管理入口暴露增加了被针对性攻击的风险，定为低危。 |
| 修复建议 | 监控控制台绑定内网/VPN访问或增加认证白名单。 |


## 三、信息级安全配置建议（非漏洞）

**IN-01（对应TC-10）：HTTP安全响应头配置不完整**

- 现象说明：教务与认证系统安全头不齐全。
- 加固建议：补齐安全头。

**IN-02（对应TC-07）：技术栈信息暴露建议**

- 现象说明：部分页面可识别框架与组件特征。
- 加固建议：统一错误处理与版本隐藏。


## 四、总体评价

沈阳工学院本次测试共覆盖28项WSTG标准测试点与若干专项扩展验证。系统核心安全机制（认证鉴权、输入验证、访问控制、会话管理、文件处理）整体有效，未发现高危漏洞；中低危问题数量少且利用条件受限。建议优先处置中危项并将信息级建议纳入日常配置基线，定期复测。
