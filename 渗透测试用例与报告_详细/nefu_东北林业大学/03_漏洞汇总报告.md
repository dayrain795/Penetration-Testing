# 03 安全测试结果汇总报告

**测试对象**：东北林业大学
**分级标准**：GB/T 30279-2020（高危/中危/低危/信息）；信息级为配置优化建议，不属于安全漏洞。

## 一、风险统计总览

| 风险等级 | 数量 | 说明 |
| :--- | :--- | :--- |
| 高危 | 0 | 未发现可直接获取系统权限、核心数据或大规模敏感信息泄露的问题 |
| 中危 | 0 | 需一定条件利用、可造成有限敏感信息泄露或防护绕过的问题 |
| 低危 | 1 | 信息泄露、配置缺陷等难以直接形成攻击链的问题 |
| 信息 | 2 | 配置优化建议/安全预警，不属于漏洞 |

## 二、安全漏洞明细

### VULN-01：部分应用会话Cookie缺少Secure属性

| 项目 | 内容 |
| :--- | :--- |
| 风险等级 | 低危 |
| WSTG编号 | WSTG-SESS-002 |
| 受影响资产 | 东北林业大学相关Web资产 |
| 漏洞描述 | 个别HTTPS应用的会话Cookie未设置Secure属性，存在会话经明文通道泄露的理论风险。 |
| 复现步骤 | 1.登录应用抓取Set-Cookie；2.核验HttpOnly/Secure/SameSite；3.确认Secure缺失但站点已强制HTTPS跳转。 |
| 定级依据（GB/T 30279-2020） | 站点已强制HTTPS跳转，实际利用条件受限，定为低危。 |
| 修复建议 | 为全部会话Cookie补充Secure与SameSite属性。 |


## 三、信息级安全配置建议（非漏洞）

**IN-01（对应TC-10）：HTTP安全响应头配置不完整**

- 现象说明：部分系统缺少CSP与X-Frame-Options。
- 加固建议：补齐安全头。

**IN-02（对应TC-09）：错误页信息建议收敛**

- 现象说明：错误页可识别应用容器类型。
- 加固建议：统一错误处理。


## 四、总体评价

东北林业大学本次测试共覆盖28项WSTG标准测试点与若干专项扩展验证。系统核心安全机制（认证鉴权、输入验证、访问控制、会话管理、文件处理）整体有效，未发现高危漏洞；中低危问题数量少且利用条件受限。建议优先处置中危项并将信息级建议纳入日常配置基线，定期复测。
