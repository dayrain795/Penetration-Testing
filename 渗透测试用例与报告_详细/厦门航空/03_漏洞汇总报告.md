# 03 安全测试结果汇总报告

**测试对象**：厦门航空
**分级标准**：GB/T 30279-2020（高危/中危/低危/信息）；信息级为配置优化建议，不属于安全漏洞。

## 一、风险统计总览

| 风险等级 | 数量 | 说明 |
| :--- | :--- | :--- |
| 高危 | 0 | 未发现可直接获取系统权限、核心数据或大规模敏感信息泄露的问题 |
| 中危 | 0 | 需一定条件利用、可造成有限敏感信息泄露或防护绕过的问题 |
| 低危 | 1 | 信息泄露、配置缺陷等难以直接形成攻击链的问题 |
| 信息 | 1 | 配置优化建议/安全预警，不属于漏洞 |

## 二、安全漏洞明细

### VULN-01：部分边缘节点支持SWEET32弱加密套件

| 项目 | 内容 |
| :--- | :--- |
| 风险等级 | 低危 |
| WSTG编号 | WSTG-CRYPTO-001 |
| 受影响资产 | 厦门航空相关Web资产 |
| 漏洞描述 | 对外站点部分边缘节点仍可协商3DES等弱套件（SWEET32），协议主版本已为TLS1.2以上。 |
| 复现步骤 | 1.使用nmap ssl-enum-ciphers枚举套件；2.确认个别节点3DES套件可协商；3.使用openssl复测并记录节点。 |
| 定级依据（GB/T 30279-2020） | 仅弱套件问题且TLS主版本安全，利用条件苛刻，定为低危。 |
| 修复建议 | 在全部边缘节点移除3DES/RC4套件，统一加密套件基线并定期巡检。 |


## 三、信息级安全配置建议（非漏洞）

**IN-01（对应TC-10）：HTTP安全响应头可进一步完善**

- 现象说明：建议补充Referrer-Policy与Permissions-Policy。
- 加固建议：补齐安全头。


## 四、总体评价

厦门航空本次测试共覆盖28项WSTG标准测试点与若干专项扩展验证。系统核心安全机制（认证鉴权、输入验证、访问控制、会话管理、文件处理）整体有效，未发现高危漏洞；中低危问题数量少且利用条件受限。建议优先处置中危项并将信息级建议纳入日常配置基线，定期复测。
