# 03 安全测试结果汇总报告

**测试对象**：南宁学院
**分级标准**：GB/T 30279-2020（高危/中危/低危/信息）；信息级为配置优化建议，不属于安全漏洞。

## 一、风险统计总览

| 风险等级 | 数量 | 说明 |
| :--- | :--- | :--- |
| 高危 | 0 | 未发现可直接获取系统权限、核心数据或大规模敏感信息泄露的问题 |
| 中危 | 0 | 需一定条件利用、可造成有限敏感信息泄露或防护绕过的问题 |
| 低危 | 1 | 信息泄露、配置缺陷等难以直接形成攻击链的问题 |
| 信息 | 2 | 配置优化建议/安全预警，不属于漏洞 |

## 二、安全漏洞明细

### VULN-01：登录失败提示存在响应差异可辅助用户名枚举

| 项目 | 内容 |
| :--- | :--- |
| 风险等级 | 低危 |
| WSTG编号 | WSTG-ATHN-004 |
| 受影响资产 | 南宁学院相关Web资产 |
| 漏洞描述 | 教务系统登录接口在账号不存在与密码错误两种情况下的响应长度/字段存在轻微差异，可被用于账号存在性判断。 |
| 复现步骤 | 1.分别提交存在与不存在的账号；2.使用Burp Suite比对响应长度与JSON字段；3.确认差异稳定可区分；4.以2秒间隔有限次验证后停止。 |
| 定级依据（GB/T 30279-2020） | 差异较小且有验证码与频控防护，仅能判断账号存在性，定为低危。 |
| 修复建议 | 统一两类失败场景的响应文案、字段与长度，仅返回模糊提示。 |


## 三、信息级安全配置建议（非漏洞）

**IN-01（对应TC-10）：HTTP安全响应头配置不完整**

- 现象说明：主站安全头不齐全。
- 加固建议：补齐安全头。

**IN-02（对应TC-09）：服务器版本信息收敛建议**

- 现象说明：响应头可识别容器类型。
- 加固建议：隐藏版本。


## 四、总体评价

南宁学院本次测试共覆盖28项WSTG标准测试点与若干专项扩展验证。系统核心安全机制（认证鉴权、输入验证、访问控制、会话管理、文件处理）整体有效，未发现高危漏洞；中低危问题数量少且利用条件受限。建议优先处置中危项并将信息级建议纳入日常配置基线，定期复测。
