# 03 安全测试结果汇总报告

**测试对象**：绵阳师范学院
**分级标准**：GB/T 30279-2020（高危/中危/低危/信息）；信息级为配置优化建议，不属于安全漏洞。

## 一、风险统计总览

| 风险等级 | 数量 | 说明 |
| :--- | :--- | :--- |
| 高危 | 0 | 未发现可直接获取系统权限、核心数据或大规模敏感信息泄露的问题 |
| 中危 | 1 | 需一定条件利用、可造成有限敏感信息泄露或防护绕过的问题 |
| 低危 | 1 | 信息泄露、配置缺陷等难以直接形成攻击链的问题 |
| 信息 | 2 | 配置优化建议/安全预警，不属于漏洞 |

## 二、安全漏洞明细

### VULN-01：部分对外系统启用TLS1.0/1.1及SWEET32弱加密套件

| 项目 | 内容 |
| :--- | :--- |
| 风险等级 | 中危 |
| WSTG编号 | WSTG-CRYPTO-001 |
| 受影响资产 | 绵阳师范学院相关Web资产 |
| 漏洞描述 | 部分对外Web系统仍协商TLS1.0/1.1协议，并支持3DES等64位分组弱套件（SWEET32，CVE-2016-2183），可被中间人降级或利用生日界攻击解密会话。 |
| 复现步骤 | 1.使用 openssl s_client -tls1_0/-tls1_1 分别握手确认旧协议可协商；2.使用nmap --script ssl-enum-ciphers枚举套件，确认3DES套件可用；3.使用testssl.sh复测确认弱套件与SWEET32告警；4.记录受影响域名与协商结果。 |
| 定级依据（GB/T 30279-2020） | 依据GB/T 30279-2020，弱协议/弱套件可被中间人利用但需要特定网络位置与条件，且不直接泄露业务数据，定为中危。 |
| 修复建议 | 禁用TLS1.0/1.1，仅保留TLS1.2/1.3；移除3DES/RC4/EXPORT等弱套件；配置HSTS并在CDN/负载均衡层统一下发。 |

### VULN-02：错误页面回显代理组件信息

| 项目 | 内容 |
| :--- | :--- |
| 风险等级 | 低危 |
| WSTG编号 | WSTG-CONF-002 |
| 受影响资产 | 绵阳师范学院相关Web资产 |
| 漏洞描述 | 部分系统错误页回显了反向代理组件类型，建议统一错误页。 |
| 复现步骤 | 1.访问随机错误路径；2.观察错误页中代理标识；3.多系统交叉验证。 |
| 定级依据（GB/T 30279-2020） | 仅为组件类型信息，定为低危。 |
| 修复建议 | 统一错误页面并隐藏代理标识。 |


## 三、信息级安全配置建议（非漏洞）

**IN-01（对应TC-10）：HTTP安全响应头配置不完整**

- 现象说明：部分系统安全头不齐全。
- 加固建议：统一补齐安全头基线。

**IN-02（对应TC-12）：默认应用路径建议收敛**

- 现象说明：个别默认管理路径可达登录页。
- 加固建议：移除默认应用，限制来源。


## 四、总体评价

绵阳师范学院本次测试共覆盖28项WSTG标准测试点与若干专项扩展验证。系统核心安全机制（认证鉴权、输入验证、访问控制、会话管理、文件处理）整体有效，未发现高危漏洞；中低危问题数量少且利用条件受限。建议优先处置中危项并将信息级建议纳入日常配置基线，定期复测。
